⭐ الطريقة الموصى بيها — ملف إعدادات محمول (JSON)Recommended: Portable Config File
دي الطريقة اللي هتشتغل معاك **من أي جهاز وأي مكان** بدون ما تعتمد على Claude خالص. بتصدّر كل مدخلاتك في ملف صغير (JSON)، وترفعه على أي حاجة تختارها (GitHub، Google Drive، إيميلك، فلاشة)، وترجع تفتحه في أي وقت على أي كمبيوتر — الملف ده هو "قاعدة البيانات" المحمولة بتاعتك.
إزاي تستخدمها مع GitHub (مجاني ومتاح من أي مكان)
  1. اعمل حساب مجاني على github.com (لو مش عندك)
  2. اعمل Repository جديد (يفضّل Private)
  3. اضغط "⬇ تصدير" فوق، وارفع الملف اللي نزل (وكمان ممكن ترفع نسخة من ملف الـHTML ده نفسه) على الـRepository بزرار "Add file → Upload files"
  4. في أي جهاز تاني: نزّل الملفين من GitHub، افتح الـHTML، واستخدم "استيراد" فوق وارفعله ملف الـJSON
بدائل أسهل من GitHub لو مش عايز تتعامل معاه: ارفع نفس ملف الـJSON على Google Drive أو ابعته لنفسك بالإيميل كمرفق.
